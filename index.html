Accessibility Widget Integration

A lightweight, plug-and-play accessibility engine for web applications. Easily integrate custom contrast, screen reader tools, and interactive accessibility controls.

View on GitHub
👇

Want to try this out? Look at the bottom-right corner of your screen and click the ♿ Accessibility button!

Integration Guide & Configuration Workflow
Structure Recommended Folder Setup

Ensure your directory structure matches the script pathways used by the widget module: 


project-root/
├── index.html
└── v4/
    └── public/                         <-- Copy this entire folder directly into your project directory
        ├── accessibility_config.js     <-- [CONFIG] Set your custom parameters & API endpoints here
        ├── accessibility/
        │   ├── css/
        │   │   └── accesibility-style.min.css
        │   └── js/
        │       ├── accessibility.min.js    <-- Core unminified engine source
        │       └── accessibility.min.js<-- [RECOMMENDED] Production-ready minified engine script
        └── draggable/
            ├── draggable.js            <-- Module entry point loaded in index.html
            └── FDraggable.js           <-- Internal dependency used under the hood by draggable.js
Step 1 Define Target Button Container

Place an empty <div> element with a unique ID wherever you want the widget trigger button to load: 

<!-- Target Container -->
<div id="accessabilityBtnSection"></div>
Step 2 Configure Widget Settings

In v4/public/accessibility_config.js, configure the trigger button markup, background color, and target container ID: 

var isPageLoaded = false;
var isAllAjaxComplete = true; 
var isAccessabilityRendered = false;

const accessabilityBtnHtml = `<button class="btn btn-primary" type="button" title="Accessibility Features">Accessibility</button>`;

const CONFIGURATION_OPTIONS = {
    backgroundColor: '#FF9800',
    // [OPTIONAL] Default width is 400px. Accepts any valid CSS unit (e.g., "400px", "100vw").
    // widget_width: "400px",  

    // [OPTIONAL] Default height is max-content. Accepts any valid CSS unit (e.g., "500px", "80vh").
    // widget_height: "80vh", 
    accessabilityBtnContainer: 'accessabilityBtnSection',
};
Step 3 Include JavaScript Modules (Strict Order)

Include core dependencies at the end of the <body> tag in this exact sequence: 

<!-- 1. Accessibility Core Engine -->
<script src="v4/public/accessibility/js/accessibility.min.js"></script>

<!-- 2. Widget Configuration & Auto-Initialization -->
<script class="erasableJsSrc" src="v4/public/accessibility_config.js"></script>

<!-- 3. Draggable Component Module -->
<script class="erasableJsSrc" type="module" src="v4/public/draggable/draggable.js"></script>
Step 4 Complete HTML Boilerplate

Copy and paste this final minimal template directly into your web page: 

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Your Web Page</title>

    <!-- 1. Accessibility Widget Stylesheet -->
    <link rel="stylesheet" href="v4/public/accessibility/css/accesibility-style.min.css" />
  </head>
  <body>
    <!-- Accessibility Trigger Container -->
    <div id="accessabilityBtnSection"></div>

    <!-- Your regular page content goes here -->

    <!-- 2. Core Accessibility Engine -->
    <script src="v4/public/accessibility/js/accessibility.min.js"></script>

    <!-- 3. Widget Configuration & Auto-Initialization -->
    <script class="erasableJsSrc" src="v4/public/accessibility_config.js"></script>

    <!-- 4. Draggable Module -->
    <script class="erasableJsSrc" type="module" src="v4/public/draggable/draggable.js"></script>
  </body>
</html>
