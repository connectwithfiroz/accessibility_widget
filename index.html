Accessibility Widget Integration

A lightweight, plug-and-play accessibility engine for web applications. Easily integrate custom contrast, screen reader tools, and interactive accessibility controls.

View on GitHub
👇

Want to try this out? Look at the bottom-right corner of your screen and click the ♿ Accessibility button!

Integration Guide & Configuration Workflow
Step 1 Add Token Meta Tag

Add the acc_tkn meta tag inside your page's <head> section to pass authentication to the backend API: 

<meta name="acc_tkn" content="YOUR_ACCESS_TOKEN_HERE">
Step 2 Define Target Button Container

Place an empty <div> element with a unique ID wherever you want the widget trigger button to load: 

<!-- Target Container -->
<div id="accessabilityBtnSection"></div>
Step 3 Configure Widget Settings

In public/accessibility_config.js, configure the trigger button markup, background color, target container ID, and backend authentication endpoint: 

var isPageLoaded = false;
var isAllAjaxComplete = true; // Set to false if you track global AJAX requests
var isAccessabilityRendered = false;

const accessabilityBtnHtml = `<button class="btn btn-primary" type="button" title="Accessibility Features">Accessibility</button>`;

const CONFIGURATION_OPTIONS = {
    backgroundColor: '#FF9800',
    accessabilityBtnContainer: 'accessabilityBtnSection', // Container ID
    // accessabilityBtn : 'Accessability', //pass any html or text (If you'll not pass anything then default btn will appear)
    authentication_check_api_url: 'http://localhost/accessability_widget/v3/api/index.php/authenticate'
};
Step 4 Include JavaScript Modules (Strict Order)

Include core dependencies at the end of the <body> tag in this exact sequence: 

<!-- 1. Accessibility Core Engine -->
<script src="v3/public/accessibility/js/accessibility.js"></script>

<!-- 2. Widget Configuration & Auto-Initialization -->
<script class="erasableJsSrc" src="v3/public/accessibility_config.js"></script>

<!-- 3. Draggable Component Module (Uses draggable/FDraggable.js under the hood) -->
<script class="erasableJsSrc" type="module" src="v3/public/draggable/draggable.js"></script>
